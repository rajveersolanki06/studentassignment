# Student Assignment Management System

## 1. Project Name

Student Assignment Management System

---

## 2. Project Objective

The objective of this project is to create a simple website
for managing student assignments.

Students can view assignments, check deadlines and mark
assignments as submitted.

Teachers can add, edit and delete assignments and view
student submission status.

---

## 3. Features

- Student Login
- Teacher Login
- Student Dashboard
- Teacher Dashboard
- View Assignments
- Add Assignment
- Edit Assignment
- Delete Assignment
- Mark Assignment as Submitted
- Submission Date
- Student List
- Submission Tracking
- About Page
- localStorage

---

## 4. Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

No backend, database, framework or API is used.
